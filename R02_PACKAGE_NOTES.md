# R02 Package Notes

Date: 2026-06-08

This folder is a local no-raw-data reproducibility package prepared for the target-journal revision of:

**Auditing open footprint proxies for urban carbon screening**

## Included

- Code for rebuilding the R02 figure/table layer.
- Derived benchmark tables, interval diagnostics, stress-test summaries, and Shenzhen proxy summaries.
- SVG/PDF/PNG figure outputs.
- Dataset/source links and public runbook material.

## Excluded

- Active submission manuscripts.
- Internal R01/R02 round files.
- Adversarial reviewer discussions.
- Cover letters and response drafts.
- Raw third-party data.
- Event-level Overture proxy rows.
- Any credentials, tokens, browser/session files, or private logs.

## Publication Boundary

This package is prepared locally. It has not been pushed in this R02 round. The intended public remote is:

https://github.com/Johnsonlijian/P3-building-footprint-proxy-benchmark

Human approval is required before publishing, pushing, or changing repository visibility.
